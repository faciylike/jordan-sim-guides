## 频段、APN与设备兼容性

　　这可能是最技术性但又最容易被忽略的一环。约旦主要采用LTE频段3和20——你的手机支持吗？绝大多数近几年产的全球版手机（如iPhone、三星Galaxy系列）都没问题，但如果你带的是某些特定地区的版本，最好提前查一下。
